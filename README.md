# 溯时：荆楚遗珍 · wmx5

## wmx5 修改

- 合瓦形改为四选一截面辨认。四张图只标甲、乙、丙、丁，不在选项文字中泄露器形名称；选错不推进，选对才显示继续按钮。
- 合奏先自由试音，至少听过两种不同钟声后开始跟奏。
- 跟奏使用《小星星》开头“一闪一闪亮晶晶”：C C G G A A G，对应宫、宫、徵、徵、羽、羽、徵。歌词谱条与下一口钟逐音高亮；支持鼠标和数字键1–5。末音在示范中延长一拍。
- 示范可重听，错误音不清空前面的进度；自由试音记录、跟奏阶段与当前音位保存到账号存档。关掉弹窗或切场景会停止示范。
- 奏完可重奏，也可继续任务；礼乐任务完成后直达考古、考古完成后自动返馆的逻辑保留。

运行：Node.js 下执行 `node server.cjs` 或双击启动脚本，访问 **http://127.0.0.1:4183/**。请勿继续打开旧端口。

`tests/music.html` 为独立演示账号的四选一与音乐交互验收页。`node tests/navigation.cjs` 同时验证小星星音序、末音时值及存档字段恢复。下方保留前版说明，启动端口以本节为准。

## 本次修改

- “离开此地”返回当前地点门前的安全坐标，不再使用上次可能位于入口内的全景坐标。
- 每次切换后，角色需先处于入口触发区域外，才允许自动进门；旧入口存档也会安全迁移。
- 曾国礼乐殿的编悬、乐师任务完成后，两个出口与“离开此地”均直达1978年考古现场，无需走全景地图。未完成时仍可自由进出。
- 重绘全景：西岸为楚宫与工坊，中央是送钟古道、江河与渡口，东岸是曾国礼乐殿。入口按最终画面的门前院落校准，不再离建筑很远。
- 渡口有东西两岸入口；走完古道东出口会落在全景东岸，可继续前往曾国，不必再折回西岸重过一次桥。
- 其余四个地点也更新为暖纸底、细墨线、灰绿与朱红的彩绘风格：古道渡口、曾国礼乐殿、1978年考古现场、未来博物馆。
- 全部地点内地图缩至1260×840，角色、NPC、任务物件、出口、碰撞共同缩放；主要活动区紧凑。全景保持1800×1200并完整显示。
- 古道横向过桥，礼乐殿中央短动线，考古现场坑前横向工作区，未来馆开放式中央空间。保留王宫和工坊的双门布局。

## 主要文件

- `js/navigation.js`：统一地点坐标、门前入口、安全落点、入口保护、礼乐直达考古、紧凑地图与最终碰撞校准。
- `js/router.js`：离开按钮使用当前位置对应的目标，避免复用旧全景坐标。
- `js/scene-manager.js`：出生位置恢复、出口重新启用条件、实际切换。
- `assets/*-wmx3.png`：本轮五张图片；王宫和工坊沿用 `*-wmx2.png`。

图片使用内置 imagegen 生成，提示词保存在 `assets/wmx3-prompts.json`。统一要求3:2近俯视、暖纸底、细墨线、低饱和灰绿与朱红；各地点分别按古道河桥、钟架礼乐殿、发掘坑工作区、未来展示馆和楚曾两岸全景设计。所有图为游戏演绎，不是地理或建筑考据复原。图片之外有独立角色、NPC、任务物件与碰撞层。
